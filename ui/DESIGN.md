# Design notes

How the web UI looks and moves, and why.

## The idea: a lab notebook

agents-lib's agents show their work: they read code, mark the evidence, and weigh it for and
against. The UI looks like that work: warm paper, ink, and a highlighter that marks what
matters.

- **The mark** is a page of notes in an ink tile, with one line highlighted.
- **The highlighter** is the signature. It marks the key phrase on the home page, the active
  navigation item, the current stage of a run, selected text, and evidence lines.
- **Paper** shows as a faint dot grid behind the two hero panels, and as tilted sheets in the
  illustrations. Shadows are warm, like paper on a desk.
- **The code minimap** stands in for a file: rounded bars indented like code. On the home
  page, two lines carry margin notes, one for and one against. On a live run, a highlight
  steps down the file line by line, the way the agent reads it.

## Principles

We took these from the best product design we know, including the research behind Google's
Material 3 Expressive. We took the principles only, never anyone's brand.

- **Simple, with a few complex touches.** There are two hero moments: the home page (headline,
  launcher, evidence sheet) and the live run (wavy progress, reading minimap). Lists, forms
  and results stay plain and quiet.
- **Motion has a job.** It shows where something came from, or that work is happening, and
  it never plays just to be seen. Springs settle with a little overshoot.
  `prefers-reduced-motion` turns it all off.
- **Tone, not lines.** Containers are filled tones of paper; hairline outlines appear only
  where something must be separated.
- **Sentence case, labels on icons**, and evidence as selectable text in a monospace face.
- **Our own identity.** We use no other company's logo, logo colours, brand typefaces or
  recognisable product motifs.

## Tokens

All tokens live in `src/styles/`.

- **Colour:** `theme.css` is generated by `scripts/gen-theme.mjs` with
  `@material/material-color-utilities`, from three palettes of our own: deep ink teal
  (primary; HCT hue 186), highlighter amber (tertiary; hue 84), and warm paper neutrals
  (hue 95, chroma 4). It covers light and dark, and adds `--marker` and `--marker-strong`
  for the highlighter.
- **Type:**
  - Fraunces for display text and headings, with its "soft" axis turned up so it feels
    friendly, not academic.
  - Instrument Sans for the interface.
  - JetBrains Mono for code and evidence.
  - All three are bundled (SIL Open Font License).
- **Icons:** Phosphor, regular weight, and duotone for the active navigation item. Every
  icon the UI uses is listed in `src/components/icons.ts`.
- **Shape:** 4, 8, 12, 16, 20, 28, 32, 48 and pill. Avatars are rounded tiles (30%).
- **Motion:** easings `cubic-bezier(.2,0,0,1)` (standard) and `(.05,.7,.1,1)` (decelerate).
  The springs come in fast, default and slow (damping 0.6 to 0.8), plus non-bouncy effect
  springs. They are generated as CSS `linear()` curves.
