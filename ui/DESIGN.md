# Design notes

How the web UI looks and moves, and why. It follows the way Google builds its own product
sites (Material 3 and its 2025 "Expressive" update, Gemini, NotebookLM, Google Fonts,
Google Labs), adapted to a tool people use to run agents and read evidence.

## What Google does, and what we take from it

| Seen on | Pattern | Here |
|---|---|---|
| Gemini, NotebookLM | Off-white canvas, almost no borders; depth comes from tonal surfaces, not shadows | Surfaces are steps of one neutral palette (`--surface` … `--surface-container-highest`) |
| NotebookLM | One huge, light headline; a single phrase in a blue gradient; soft multi-hue wash at the top of a 32 px-radius panel | The home hero |
| Gemini | Pill-shaped input with a soft shadow and a blue glow breathing behind it | The home launcher: pick an agent, paste its main input, go |
| m3.material.io, Google Fonts | Quiet navigation rail: thin rounded icons, tiny labels, a pill indicator behind the active item | The left rail |
| Material 3 Expressive | Abstract shapes (cookie, clover, pentagon) used as decoration and avatars | Each agent gets a shape with its monogram, coloured from its id |
| Material 3 Expressive | Spring motion, which overshoots a little and then settles | Springs written as CSS `linear()` curves, generated from the M3 spring constants |
| Google research (46 studies) | Expressive design helps people find key elements up to 4× faster, but only with one or two hero moments and plain, functional basics | Two hero moments (home launcher, live run). Everything else stays calm |

## Rules

- **Two hero moments only.** The home launcher and the live run. Lists, forms and results
  stay plain and quiet.
- **Sentence case everywhere.** "Max files for judge", not "Max Files For Judge".
- **Tonal, not outlined.** Containers are filled tones. Hairline outlines appear only where
  something must be separated, such as a list row or a text field.
- **Labels on icons.** Every icon in the rail has a text label; no icon-only mysteries.
- **Motion has a job.** It shows where something came from, or that work is happening. It
  never plays just to be seen. `prefers-reduced-motion` turns it all into fades.
- **Evidence is text.** Locations, quotes and JSON use Google Sans Code. They can be
  selected and copied, never hidden behind hovers.

## Tokens

All tokens live in `src/styles/`. `theme.css` is generated by `scripts/gen-theme.mjs` from
one seed colour using Google's own colour library (`@material/material-color-utilities`,
vibrant scheme, seed `#0b57d0`), in light and dark.

- **Type:** Google Sans Flex (variable: weight, width, optical size, roundness) with the M3
  type scale: display 57/45/36, headline 32/28/24, title 22/16/14, body 16/14/12,
  label 14/12/11. Headlines use weight 400; display text drops to weight 350.
- **Shape:** 4, 8, 12, 16, 20, 28, 32, 48 and full (pill), as in M3.
- **Motion:** M3 durations (50–1000 ms) and easings (emphasized `cubic-bezier(.2,0,0,1)`).
  The springs are spatial default (damping 0.8, stiffness 380), fast (0.6 / 800) and
  slow (0.8 / 200), plus effects (damping 1, stiffness 1600) for colour and opacity.
- **Icons:** Material Symbols Rounded, weight 300, optical size 24, unfilled. An icon fills
  only when it is selected.
